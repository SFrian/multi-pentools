# AutoPent

AutoPent adalah alat otomatis untuk melakukan serangan **Slow HTTP** menggunakan `slowhttptest`.

## 📌 Fitur
- Menggunakan `slowhttptest` dengan parameter yang bisa dikonfigurasi.
- Menyimpan log waktu mulai dan selesai serangan.
- Mudah diatur dengan file konfigurasi.

## 🚀 Cara Instalasi
```bash
git clone https://github.com/username/autopent.git
cd autopent
chmod +x autopent.sh
